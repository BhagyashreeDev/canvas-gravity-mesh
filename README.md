# Canvas Gravity Mesh

A simple, interactive dot grid built with HTML5 Canvas and vanilla JavaScript. The dots react to the mouse cursor, dynamically changing size to create a magnetic "gravity" effect as you move around the screen.

## Features
* Interactive physics-based mouse tracking and distance calculation.
* Fully responsive grid that automatically adapts to browser window resizing.
* Lightweight performance with zero external libraries or dependencies.

## How to Run Locally
1. Download or clone this repository to your machine.
2. Ensure both `index.html` and `script.js` are in the same directory.
3. Open the `index.html` file directly in any modern web browser.
4. Move your mouse across the screen to interact with the mesh.

## Technologies Used
* HTML5 (Canvas API)
* CSS3
* Vanilla JavaScript
